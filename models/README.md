# Model Weights

Place trained TCN weights here as `tcn_weights.pt`.

## Expected input/output shapes

| Tensor          | Shape         | Notes |
|-----------------|---------------|-------|
| Input           | `(1, 20, 16)` | batch=1, FEATURE_DIM=20, SEQUENCE_LENGTH=16 |
| anomaly_logit   | `(1,)`        | raw logit; `sigmoid` → score in [0, 1]; >0.85 triggers alert |
| class_logits    | `(1, 5)`      | raw logits; `argmax` → activity class index |

## Activity classes

| Index | Label        |
|-------|-------------|
| 0     | normal       |
| 1     | shellcode    |
| 2     | rootkit      |
| 3     | cryptominer  |
| 4     | ransomware   |

## Saving after training

```python
from model.tcn import save_model

# train your model…
save_model(trained_model, "../models/tcn_weights.pt")
```

## Loading

`load_model()` (called automatically by `analyzer.py` at startup) loads
`models/tcn_weights.pt` if it exists.  Loading uses `strict=False` so
checkpoints trained before the classification head was added still work
(the class head is randomly initialised in that case).

## Feature vector (FEATURE_DIM = 20)

| Index | Feature                   | Source       | Notes                              |
|-------|---------------------------|--------------|------------------------------------|
| 0     | byte_entropy              | page bytes   | Shannon entropy / 8, [0,1]         |
| 1     | nonzero_ratio             | page bytes   | fraction non-zero bytes            |
| 2     | printable_ratio           | page bytes   | fraction ASCII 0x20–0x7E           |
| 3     | high_byte_ratio           | page bytes   | fraction > 0x7F                    |
| 4     | unique_bytes              | page bytes   | unique values / 256                |
| 5     | top4_freq                 | page bytes   | top-4 byte frequency sum           |
| 6     | zero_runs                 | page bytes   | runs of zeros > 8B, / 100          |
| 7     | addr_norm                 | address      | physical address / 2^48            |
| 8     | entropy_blocks_std        | page bytes   | std-dev of 16×256B block entropies |
| 9     | compression_ratio         | page bytes   | zlib size / 4096                   |
| 10    | null_run_ratio            | page bytes   | bytes in zero-runs > 8B            |
| 11    | pe_header_score           | page bytes   | 0/0.5/1 PE magic strength          |
| 12    | elf_header_score          | page bytes   | 0/0.5/1 ELF magic strength         |
| 13    | syscall_pattern_count     | page bytes   | syscall opcodes / 100              |
| 14    | nop_sled_score            | page bytes   | bytes in NOP-runs > 8B             |
| 15    | string_density            | page bytes   | printable strings ≥4B, / 100       |
| 16    | entropy_delta             | temporal     | entropy change vs prev frame       |
| 17    | addr_delta                | temporal     | address jump vs prev frame         |
| 18    | kernel_module_count_norm  | OS-layer VMI | loaded modules / 200 (0 if raw)    |
| 19    | network_conn_count_norm   | OS-layer VMI | TCP connections / 100 (0 if raw)   |

## Training data format

Frames are logged by `analyzer.py --log-dir <path> --label <normal|malware>`.
Synthetic frames are generated by `training/synthetic.py`.
Each `.npy` file contains a dict with keys:

- `features`:     shape `(20,)` float32 — the input vector
- `addr`:         int — physical address
- `timestamp_ms`: int — Unix milliseconds
- `class_label`:  int — activity class 0–4
- `raw_page`:     shape `(4096,)` uint8 — raw page bytes (logged frames only)

## Using TranslateV2P for targeted scanning

When OS-layer init is active (`--sysmap configs/hyptcn-guest.sysmap`), you
can translate process virtual addresses to physical addresses and scan them
directly:

```go
procs, _ := vmiHandle.GetProcessList()
for _, p := range procs {
    pa, err := vmiHandle.TranslateV2P(p.CR3, 0x400000) // scan text segment
    if err == nil {
        page, _ := vmiHandle.ReadPage(pa)
        // feed page to analyzer...
    }
}
```
